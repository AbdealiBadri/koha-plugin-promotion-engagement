# Contributing

Thank you for improving Koha Promotion & Engagement.

1. Open an issue describing the problem, Koha version and plugin version.
2. Base changes on the active development branch named in the Project Brain.
3. Do not patch Koha core or copy patron-identifiable data into fixtures.
4. Add or update automated tests for every behavior change.
5. Run the complete test suite and KPZ integrity checks.
6. Update relevant user and technical documentation.
7. Keep commits focused and never include credentials or production data.
8. Explain schema migrations, compatibility and rollback implications in the pull request.

Bug reports should include reproduction steps, expected result, actual result and
sanitized logs. Security reports must follow SECURITY.md and must not be posted
with credentials or patron data in public issues.
