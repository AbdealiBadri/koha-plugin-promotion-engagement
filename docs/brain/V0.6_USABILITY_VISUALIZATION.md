# v0.6 Usability & Visualization

**Date:** 2026-09-23
**Branch:** `feature/v0.6-usability-visualization`
**Implementation commit:** `1f0c993`
**Plugin version:** 0.6.0
**Verified runtime:** Koha 25.11.02 KTD (`promoeng`)

## Objective

v0.6 keeps the academic/professional terminology of Promotion & Engagement while making the interface easier to understand, search, compare, filter, sort, export and act upon.

The design rule is:

- headings/KPIs/analytical terminology remain professional and academically precise;
- explanations and help text are deliberately simple, practical and beginner-friendly.

## Implemented changes

### Dashboard evidence cycle

Academic headings remain:

1. Record the promotion
2. Establish the baseline
3. Observe response
4. Present the finding

The explanatory text is simplified to:

- “These are the books/resources we promoted, and this is how and when we promoted them.”
- “How were these books/resources performing before we promoted them?”
- “After we promoted them, did students/users actually start borrowing them more?”
- “Did the promotion work, by how much, and what can the librarian learn from it?”

### Terminology

User-facing terminology is standardized:

- **Titles Issued / Borrowed** replaces “Titles Used”.
- **Titles with Increased Issues** replaces “Increased-Use Titles”.
- **Zero-Response Titles** remains the clear no-circulation category.

### Searchable selection

Growing dropdowns use searchable Select2-style controls where appropriate.

Campaign selection supports search and natural/numeric sorting. Promotions and Reports support multi-campaign selection for comparative work.

### Global tables

Major plugin tables use a shared Koha DataTables pattern with:

- search/filter;
- ascending/descending sorting;
- text/numeric/date sorting through Koha DataTables;
- export/download capability through Koha table tools;
- consistent styling.

### KPI drill-down

Interactive KPI cards can filter/jump to their supporting table state, including:

- Titles Issued / Borrowed;
- Zero-Response Titles;
- Titles with Increased Issues;
- Resource Impact workflow states.

### Resource Impact

Promoted Resource Impact adds:

- green cue for strongest/highest campaign-period issuing evidence;
- red cue for zero issue response;
- accessible text/legend so color is not the only signal;
- filtering/sorting around circulation and purchase-suggestion workflow states;
- redesigned Collection-development signals presentation.

### Campaign Analytics

All existing v0.5 evidence remains.

The page is reorganized into a clearer hierarchy and adds:

- Chart View / Table View;
- professional analytical charts;
- data labels;
- JPEG chart download;
- searchable/sortable/exportable detailed title table.

Charts do not replace tables or change formulas.

### Comparative Reports

Existing comparative tables and methodology remain.

v0.6 adds:

- comparative charts;
- Chart View / Table View;
- data labels;
- JPEG download;
- multi-campaign selection;
- searchable/sortable/exportable tables.

Multi-location attribution safeguards remain unchanged.

### How to Use

A page-specific **How to Use** control is included across the major workflow surfaces:

- Dashboard;
- New Promotion;
- Promotions;
- Campaign Detail;
- Edit Promotion;
- Campaign Analytics;
- Promoted Resource Impact;
- Comparative Reports;
- Configuration.

The help explains, in very simple language:

- what the page is for;
- what each section means;
- what the KPIs mean;
- what to click first;
- what each action does;
- which actions write data;
- how to search/filter/sort/export;
- what to avoid;
- what success looks like.

### Configuration

Configuration help explicitly explains:

- Campaign types;
- Channels;
- Locations;
- Languages;
- Audiences;
- Cadence / frequency;
- Stable code;
- Display label;
- Sort order;
- Active/Disable behavior;
- historical-data implications.

The plugin continues to ship defaults while allowing institutions to create their own reusable vocabulary without source-code changes.

## Upgrade/data-preservation behavior

v0.6 is an in-place upgrade of the same plugin class.

No new core Koha table/column is introduced.

The exact-KPZ upgrade smoke verifies the seven plugin table row counts before and after upgrade and fails if they change unexpectedly.
