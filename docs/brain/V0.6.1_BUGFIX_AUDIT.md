## Scope

This release intentionally makes no product/visual redesign. It preserves the v0.6 user interface and functionality and focuses only on reliability, data integrity, analytics correctness, input validation, concurrency safety, export safety and test robustness.

## Defects found and corrected

1. **Future/scheduled campaigns distorted portfolio KPIs.** Pending campaigns could enter portfolio denominators and depress title utilization / create false zero-response titles. They are now excluded from measured portfolio/comparison results while still retained in selected-scope metadata.
2. **Recommendation decision race condition.** Decision save and audit were not protected by a row lock/transaction. They are now atomic under `FOR UPDATE` with rollback on failure.
3. **Native Koha Suggestion duplicate-submission race.** Concurrent submission could create duplicate native suggestions. Submission now locks the recommendation, verifies approved/unsubmitted state inside the transaction, uses a guarded update and rolls back on any race/failure.
4. **CSV spreadsheet formula injection.** Exported values beginning with spreadsheet formula characters, including leading whitespace, are neutralized before CSV output.
5. **Invalid calendar dates passed format-only validation.** Dates such as 2026-02-29 or day 00 are now rejected using actual calendar-date validation.
6. **Open active campaigns filtered incorrectly in reports.** Report overlap filtering now treats an active open/future-ended campaign as running through today, matching Analytics semantics.
7. **Legacy language/audience values could be silently rewritten.** Existing historical selections are preserved exactly while new/changed values are validated against configured vocabulary.
8. **Forged optional vocabulary values could be posted.** New/changed language and audience values must match configured active values when vocabulary exists.
9. **Campaign selectors were silently capped.** Analytics and Resource Impact selector queries no longer stop at 200 campaigns.
10. **DataTable KPI highlighting was page-local.** Drill-down highlighting now clears/applies across all filtered DataTable rows, not only the visible page.
11. **Decimal hold-ratio quantity edge case.** Additional-copy calculation now uses mathematical ceiling correctly for decimal `HoldRatioDefault` values.
12. **Report comparison performance.** Campaign checkout evidence can be cached request-locally and reused across comparison dimensions, avoiding repeated identical circulation queries without persisting stale data across requests.
13. **Stray production debug logging.** Temporary `PE_DEBUG` output was removed.
14. **Exact-KPZ smoke race after Plack restart.** The package test now waits for the Koha staff interface to become ready before continuing.
